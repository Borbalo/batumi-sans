# Languages

Batumi Sans supports 632 living languages in its four scripts: Georgian, Latin, Cyrillic and Greek. Every style of Batumi Sans and Batumi Sans Rounded supports the same languages.

| Script | Languages |
|---|---|
| Georgian | 4 |
| Latin | 542 |
| Cyrillic | 92 |
| Greek | 3 |

A few languages are written in two of these scripts and appear in both lists.

## Languages of Europe

The fonts cover the national language of every European state except Armenian, which we plan to add:

Albanian, Azerbaijani, Belarusian, Bosnian, Bulgarian, Catalan, Croatian, Czech, Danish, Dutch, English, Estonian, Finnish, French, Georgian, German, Greek, Hungarian, Icelandic, Irish, Italian, Latvian, Lithuanian, Luxembourgish, Macedonian, Maltese, Montenegrin, Norwegian, Polish, Portuguese, Romanian, Romansh, Russian, Serbian, Slovak, Slovenian, Spanish, Swedish, Turkish, Ukrainian.

## Languages of Georgia

Of the languages spoken in Georgia, the fonts cover Georgian, Mingrelian, Laz, Svan, Abkhaz, Ossetian, Azerbaijani and Russian. Armenian is planned.

## How this was counted

The list comes from [Hyperglot](https://hyperglot.rosettatype.com) 0.8.2, an open database of the characters each language needs. A language is listed when the fonts have every base character of its main spelling. To make the list again, run `python scripts/list_languages.py`.
